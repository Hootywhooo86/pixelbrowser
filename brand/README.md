# Bit Browser brand

- **Logo:** the chunky pixel letter mark drawn by `scripts/make-icons.py`, the same style and colors as the original "P", redrawn as a **"B"**. That's the owner's decision.
- `bit-browser-logo-source.jpg`: an alternative artwork the owner sent (a pixel browser window with a binary globe). It is **not used** for now. Keep it for later.
- Colors stay the current palette: navy `#0b0b16`, teal `#2dd4bf`, orange `#ff9f1c`.
- The AI assistant is called **Bitter**.


## Logo (from 0.6.0): the Bit Globe

Picked by the user from 12 options: a 128x128 pixel-art teal globe with an
orange ring and an orange B, on the navy/purple pixel tile. It's drawn in code
by `scripts/make-icons.py`, which writes every app icon size, the Android
adaptive and themed icons, the splash icon, the favicon and the in-app logo
(`apps/mobile/assets/logo.png`, `apps/desktop/src/ui/img/logo.png`). Colors
stay navy #0b0b16, teal #2dd4bf, orange #ff9f1c.
