2FA CODES & SECURITY CHECK

Bit Browser can be your authenticator app. When a site asks for a 2FA code, it offers to fill it. Codes are encrypted with your computer's keychain and sync with "Sync passwords".

Setting up 2FA on a site? Open its QR code page and use Menu → Scan a 2FA QR code on this page.

PASSWORD SECURITY CHECK

Finds weak and reused passwords on this computer. The breach check asks Have I Been Pwned using only the first 5 characters of each password's fingerprint (hash): your passwords never leave this computer.

IMPORT & BACKUP

IMPORT FROM ANOTHER BROWSER

Passwords can't be read from other browsers directly: export them as a CSV (Chrome/Brave/Edge: Settings → Passwords → Export; Bitwarden and 1Password work too), import it here, then delete the CSV.

ENCRYPTED BACKUP

One file with your bookmarks, history, notes, packages, passwords, 2FA codes, settings and XP, locked with a passphrase only you know. Keep it somewhere safe (a USB stick, Google Drive). The phone app reads the same file.
