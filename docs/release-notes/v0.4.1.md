# Bit Browser 0.4.1: PDFs open in Bit Browser

**Pages that lead to a PDF now open it in Bit Browser's PDF viewer.**

On Android, when a link leads to a PDF (an insurance policy, an invoice, a statement, a shipping label), the phone's web engine can't show it. It used to quietly hand the file to Android's download manager instead, so nothing happened on screen. Now Bit Browser takes the file itself, using your sign-in for that site, saves it, and opens it in the built-in PDF viewer with **Print, Save, Share and Open with**.

This works for any link that leads to a PDF, even when the address doesn't end in ".pdf". Other files (like APKs, ZIPs or spreadsheets) are saved too and listed under Menu → Downloads.
