# Bit Browser 0.4.4: Shippo labels download again

**Fixed: PDF labels and invoices from Shippo (and other sites) stopped opening in 0.4.3.**

0.4.3 made "Sign in with Google" pop-ups work. But it also counted Shippo as a sign-in site, so when Shippo opened a label in a new window, it landed in a sign-in pop-up that can't show PDFs, and nothing happened.

Now:
- Files that open in a new window (PDFs, labels, invoices, spreadsheets) go to Bit Browser's downloads and PDFs open in the PDF viewer, like before.
- If a sign-in pop-up turns out to be a file, it's handed to the downloads too.
- "Sign in with Google" keeps working.
