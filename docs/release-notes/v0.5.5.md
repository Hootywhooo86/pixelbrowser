# Bit Browser 0.5.5: Shippo labels, found and fixed

Your download log showed exactly what Shippo's **Download label** does:
1. It opens an empty pop-up window.
2. It asks Shippo's server for the label.
3. It tells the pop-up to **open the label inside itself**.

Bit Browser's stand-in for that pop-up didn't understand step 3. It returned nothing, so Shippo hit an error ("Cannot read properties of null") and the label never appeared.

**Now** the stand-in understands it. The label is saved and opens in Bit Browser's **PDF viewer**, with Print, Save and Share. Labels kept on file-storage services (like Shippo's and Amazon's) are recognised as files right away.

**Computer:** the same kind of empty pop-up now opens as a real small window instead of being refused, so Shippo can put the label in it. PDFs show there with the built-in viewer.
