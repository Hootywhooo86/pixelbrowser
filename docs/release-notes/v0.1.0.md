# Pixelbrowser 0.1.0: first preview

A private, pixel-style web browser with a Comet-style AI that works with any AI you choose.

## Download

| You have | Download |
|---|---|
| **Windows** | `Pixelbrowser-Setup-0.1.0-x64.exe` (most PCs), or `-arm64.exe` for ARM laptops |
| **Mac** (Intel or Apple Silicon) | `Pixelbrowser-0.1.0-universal.dmg` |
| **Linux** | `Pixelbrowser-0.1.0-x86_64.AppImage`, or the `.deb` for Ubuntu/Debian |
| **Android** | `Pixelbrowser-0.1.0-android.apk` |

The `.aab`, `.zip`, `.blockmap` and `latest*.yml` files are for Google Play and auto-updates. You don't need to download them.

## What's in it
- Pixel-style tabs, private windows, built-in ad and tracker blocking, and Chrome extensions on desktop
- **Pixel AI**: ask about any page, compare your tabs, or ask questions straight from the address bar
- **Agent mode**: Pixel can click, type and fill in forms for you. It asks before buying, sending or logging in.
- **Any AI**: Claude, ChatGPT, Gemini, Grok, Mistral, DeepSeek, Groq, OpenRouter, Perplexity, or a local model (Ollama, LM Studio). AI web apps open in the sidebar too.
- **AI slider**: turn all AI off for fully private browsing
- **Your choice of search engine**: DuckDuckGo, Brave, Startpage, Mojeek, Google and more
- **End-to-end encrypted sync** of memory, history, open tabs and settings between your computer and phone
- Desktop updates itself automatically from now on

## This is a preview, so expect warnings
These first builds aren't code-signed yet:
- **Windows:** SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
- **Mac:** right-click the app → **Open** → **Open** the first time. Auto-update on Mac needs a signed build, so update by hand for now.
- **Android:** allow "Install unknown apps" for your browser or file manager. This preview is signed with a test key, so when the official Play Store version comes out, uninstall this one first.
- **Linux AppImage:** make it executable (`chmod +x`) and run it.
