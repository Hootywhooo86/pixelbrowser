# Bit Browser 0.6.3: mobile and desktop view

## One-tap switch
- A new **PC** button sits in the address bar. Tap it to switch the site you're on to its desktop (computer) version, and tap again for the mobile version.
- When desktop view is on, the button turns orange.
- Bit Browser remembers it per site: set Shippo to desktop once and it opens that way every time.
- Menu → Desktop site still works too.

## Desktop sites fit your screen
- Desktop view now lays the page out like a computer screen and zooms out so the whole width fits on your phone, the way Chrome does it. Before, many sites still squeezed into a phone-width layout.
- Pinch to zoom in on any part.
