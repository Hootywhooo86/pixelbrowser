# Bit Browser 0.4.2: http sites open

**Fixed "Error loading page: net::ERR_CLEARTEXT_NOT_PERMITTED".** Android blocks apps from loading plain `http://` websites (ones without encryption) unless the app says otherwise, and Bit Browser didn't. Older sites like these now open, the same as in Chrome or Brave.

They're marked **not secure** with a pink open-lock icon in the address bar. Tap it for details. Don't type passwords or card numbers on those sites.
