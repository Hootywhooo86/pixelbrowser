# Bit Browser 0.5.4: finding out what Shippo's "Download label" does

Shippo's "Download label" still doesn't open for some people. Your download log showed that Shippo opens an empty pop-up and then doesn't use it in any way Bit Browser could see. So this version records much more detail in the download log, to find exactly where the label goes:
- Each request the page makes for a few seconds after you tap, with its result and file type.
- Everything the page does with the pop-up window.
- Any error the page hits.

**Please:** tap **Download label** in Shippo once, then open Menu → Downloads → **DOWNLOAD LOG** → **SHARE** and send it. The log is only on your phone and only leaves when you share it. It contains web addresses, not passwords.
