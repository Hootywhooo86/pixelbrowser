# Bit Browser 0.5.8: downloads only when you ask

**Fixed: Bit Browser saved files you didn't ask for.** To catch Shippo's labels, recent versions saved any PDF or file link a page loaded right after any tap. That also caught pages that load PDFs in the background.

Now those catch-all checks only kick in right after you tap something that is clearly a **download or print button**, one that says Download, Label, Invoice, Receipt, PDF, Print, Export, Statement, Packing slip, Ticket and so on. Normal links and buttons never start a download.

Shippo's **Download label**, **Download packing slip** and **Download commercial invoice** still open in the PDF viewer. Real download links (and files a site sends as a download) work as before.
