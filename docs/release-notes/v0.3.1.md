# Bit Browser 0.3.1

## Download PDFs, shipping labels and invoices
- Labels and invoices you buy on sites like **Shippo** now download. Bit Browser fetches the file from inside the page, so your sign-in comes along. That includes files the site creates on the spot.
- **PDFs open right in Bit Browser**, with buttons to **PRINT** (sent to your phone's printer service, so 4×6 and letter labels come out the right size), **SAVE** to a folder you pick (like Downloads), **SHARE** and **OPEN WITH**.
- Every download is listed under Menu → Downloads. PDFs there have VIEW and PRINT buttons.
- **Computer:** PDFs open in a tab with the built-in viewer and print button. Downloads save straight to your Downloads folder, and a notice lets you open the file or show it in its folder.

## More pixel, cleaner text
- **Pixel-art icons** everywhere: Back, Forward, Reload, Bitter, Menu, the shield, lock, download, print and more, in phone and computer.
- **Fixed text overlapping lines.** Pixel lettering is now centered in its boxes and no longer spills over borders.
- Chunkier pixel buttons with a 3D bevel and hard shadow, pixel cards with notched corners, dashed pixel dividers and a segmented XP bar.
