# Bit Browser 0.5.2: Shippo "Download label" works

Thanks to the download log you sent, the Shippo problem is found and fixed.

**What was wrong:** Shippo's "Download label" first opens an **empty pop-up window**, then puts the label into it. Bit Browser shows one page per tab, so it handed Shippo a stand-in window, and that stand-in ignored whatever Shippo put in it. The label never appeared.

**Now** the stand-in is a real hidden page, and whatever Shippo puts in it is caught:
- A PDF, a link to a PDF, or a PDF inside a frame **opens in the PDF viewer** (Print / Save / Share).
- A label drawn as a web page that Shippo asks to print is **turned into a PDF** and opened in the viewer, ready to print.
- If the pop-up is sent to an ordinary page (like a sign-in), that still opens as a real pop-up.

Tested against 18 different ways sites deliver files and labels, with no duplicates. The download log (Menu → Downloads) now also records what happens inside these pop-ups, in case anything else needs fixing.
