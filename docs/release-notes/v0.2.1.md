# Bit Browser 0.2.1

A quick fix for the phone app.

- **Pages fill the whole screen again.** With more than one tab open, the page only used part of the screen and left an empty gap under the address bar.
- **Smoother video while scrolling.** The address bar and buttons no longer hide while a video is playing. They only slide away when you clearly scroll down, so pages and autoplay videos stop jumping around.

## Download

| You have | Download |
|---|---|
| **Android** | `BitBrowser-0.2.1-android.apk` (install it over the old one) |
| **Windows** | `BitBrowser-Setup-0.2.1-x64.exe`, or let Bit Browser update itself |
| **Mac** | `BitBrowser-0.2.1-universal.dmg` |
| **Linux** | `BitBrowser-0.2.1-x86_64.AppImage` or `.deb` |
