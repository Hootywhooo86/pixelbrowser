# Bit Browser 0.6.5: Call buttons really work now

- **Found the real cause.** The web engine Bit Browser is built on stopped phone-number links before Bit Browser could see them. It asked Android whether an app could open them, and since Android 11 the answer is "no" unless the app declares it up front, so the tap was silently dropped. Now every link comes to Bit Browser.
- **Call** on Google, and any phone number on a page, opens your phone app's keypad with the number filled in.
- Links for other apps (email, texts, maps, WhatsApp, Zoom, Spotify and so on) open their apps too.
- If something still doesn't open, Menu → Downloads → troubleshooting log shows an "app link" line for each tap.
