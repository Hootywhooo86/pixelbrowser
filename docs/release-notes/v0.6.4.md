# Bit Browser 0.6.4: Call buttons work

- **Call buttons open your phone app.** Tapping **Call** on Google (and other sites) now opens your phone app's keypad with the number filled in, ready for you to press call. Google opens these through pop-ups and special Android links, which Bit Browser used to drop.
- **Text, email and map links** (sms:, mailto:, geo: and Android "intent:" links, like Google's Directions) now open the right app too. If the app isn't installed, the web version opens in a new tab.
