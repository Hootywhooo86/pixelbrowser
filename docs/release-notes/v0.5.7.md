# Bit Browser 0.5.7: PDFs show in the viewer

**Fixed: the PDF viewer stayed on "Opening PDF…"** even though the file had downloaded.

The viewer used to download a PDF-reading program from the internet each time, and on some phones that never finished. On Android, Bit Browser now uses the phone's **own built-in PDF renderer** to draw each page. It works offline, opens quickly, and you can pinch to zoom. Shipping labels and documents show right away, with **Print, Save, Share and Open with** as before.

"Ask Bitter" about a PDF still works: it reads the PDF's text in the background.
