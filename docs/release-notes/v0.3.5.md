# Bit Browser 0.3.5: documents download

Fixed "Download failed: Failed to fetch" on sites that make documents on the spot, like insurance policy documents, invoices and shipping labels.

These sites build the file inside the page, open it, and then throw the link away a split second later. Bit Browser was a moment too slow to grab it. Now it keeps hold of every file a page makes, so it can always save it. This also works when the file is made inside a frame on the page.

PDFs open in the Bit Browser viewer (Print, Save, Share, Open with), and everything is listed under Menu → Downloads.
